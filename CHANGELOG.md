# Changelog

## 0.5.1

- README: visible note that the extension makes no model calls and no outbound requests, with a grep check.
- No code change.

## 0.5.0

- Settings box in 4 lines. Each option name has a hover text. **Show log** button replaces Configure.
- In click mode, a press anywhere on the page stops the fill.
- Log reason `click_elsewhere`.

## 0.4.0

- Optional action log (`log`, `log_hours`) with a viewer dialog.

## 0.3.0

- Misclick protection merged into two features: Click guard and Send delay (`hold`, `click`, `off`).

## 0.2.0

- Native extension settings. Configurable chip list. Fill colour and timers.

## 0.1.0

- First version: reply chips above the composer.
